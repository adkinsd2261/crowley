## Goal

Classify cognitive ingest as `store` | `ignore` | `temporary` **before** `spark_extraction` runs. Rules-first; never silently discard ambiguous input.

---

## Pipeline insertion

```
POST /api/cognitive/ingest
  → _save_cognitive_receipt (unchanged)
  → classify_memory_intent(content)   ← NEW
      → ignore     → metadata only, skip extraction
      → temporary  → receipt + audit flag, no sparks
      → store        → existing _run_extraction_pipeline
```

Today [`cognitive_ingest.py`](../cognitive_ingest.py) always calls `extract_sparks_from_text()` in `_run_extraction_pipeline`. T1 adds the branch before extraction (sync and async paths).

## New module: `cognitive_intent.py`

```python
@dataclass(frozen=True)
class MemoryIntentResult:
    intent: Literal["store", "ignore", "temporary"]
    confidence: float  # 0.0–1.0
    reason: str
```

### `classify_memory_intent(text: str) -> MemoryIntentResult`

Rule stack (deterministic, no LLM in T1):

| Order | Rule | Intent |
|-------|------|--------|
| 1 | `sparks._spark_content_security_errors()` non-empty (secrets, instructions) | `ignore` (high confidence) |
| 2 | Slash/CLI patterns (`/task`, `/remember`, leading `/`) | `ignore` |
| 3 | Noise: empty, &lt;4 meaningful chars, greeting tokens (`hey`, `ok`, `lol`, …) | `ignore` |
| 4 | Temporary markers (`remind me later today`, `just for this session`, …) | `temporary` |
| 5 | Substantive content (length + keyword heuristics) | `store` (high confidence) |
| 6 | Ambiguous remainder | `store` (low confidence) — **never silent `ignore`** |

### Principles

- Rules-first; optional model hook deferred.
- Low-confidence → `store` with tentative hint on receipt metadata (full `certainty` column in **T2**).
- `temporary` = no sparks, no normal retrieval; receipt retained with `non_retrieval: true`.
- Must not weaken T18–T20 security gates.

---

## `cognitive_ingest.py` changes

1. After receipt save, call `classify_memory_intent(content)`.
2. **`ignore`:** attach metadata `{intent, confidence, reason, extraction_status: "skipped_intent"}`; skip worker/pipeline.
3. **`temporary`:** same skip + `{retention: "audit_only", non_retrieval: true}`.
4. **`store`:** existing pipeline; if `confidence < 0.6`, add `{intent_certainty_hint: "tentative"}` on receipt (T2 wires to spark `certainty`).

### Additive API response

```json
{
  "status": "ok",
  "memory_item_id": 123,
  "intent": {"intent": "store", "confidence": 0.92, "reason": "substantive_content"},
  "extraction": { ... }
}
```

For `ignore`/`temporary`: `"extraction": {"status": "skipped", "reason": "..."}`.
