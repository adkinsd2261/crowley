# Crowley V3.9.1 — Repository & CI

**Status:** Shipped (2026-07-01)  
**Release:** `CROWLEY_VERSION = "3.9.1"`, `CROWLEY_RELEASE_LABEL = "Crowley V3.9.1 Repository & CI"`  
**Baseline:** V3.9 Concurrent Ticketing  
**Repository:** [github.com/adkinsd2261/crowley](https://github.com/adkinsd2261/crowley)

---

## 1. Purpose

V3.9 shipped concurrent ticketing but the workspace had no version-control baseline and no automated regression gate. V3.9.1 **grounds the project in git** and **runs the existing unit suite on every push**.

Problems addressed:

1. Handoff `Files Changed` sections were empty without a git baseline.
2. Fifty-two unit tests existed locally but nothing blocked regressions on `main`.
3. Onboarding docs still listed git init and CI as open gaps.

---

## 2. Shipped surface

### Git repository

| Item | Detail |
|------|--------|
| Remote | `https://github.com/adkinsd2261/crowley` on branch `main` |
| `.gitignore` | `.env`, `crowley.db`, `venv/`, `.crowley/processed/*`, bus logs |

### GitHub Actions CI

| Item | Detail |
|------|--------|
| Workflow | `.github/workflows/tests.yml` |
| Trigger | `push` and `pull_request` to `main` |
| Runner | `ubuntu-latest`, Python 3.12 |
| Command | `python -m unittest discover -s tests -q` |
| Timeout | 20 minutes (embedding model download on cold cache) |

## 5. Run commands

```bash

./venv/bin/python3 -m unittest discover -s tests -q

# Handoff with git file list
./venv/bin/python3 scripts/crowley_handoff.py --source cursor --type builder_handoff --from-git

# CI mirrors the workflow file
cat .github/workflows/tests.yml
```
