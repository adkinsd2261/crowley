## Scope

V3.9.14 made the ChatGPT bridge durable. V3.9.15 adds a **hybrid gateway toolbelt** so Custom GPT can plan, inspect, and write structured truth with Codex-parity bounds — without exposing full `/api/*`.

| In scope (#94–#100) | Out of scope |
|---------------------|--------------|
| Tool registry + POST `/read` / `/write` gateway | V4 Spark Lanes |
| GET `/catalog` tool manifest | OAuth / multi-user |
| Domain read, inspect, planning, QA tools | GitHub writes |
| Codex-parity ticket + handoff writes | Shell / code / deploy |
| Read-only GitHub proxy (`CROWLEY_GITHUB_TOKEN`) | Full internal API |
| Legacy V3.9.13 route aliases (deprecated) | |

---

## Architecture

```
Custom GPT → POST /api/actions/read|write { tool, args }
                    ↓
            actions_tool_registry.py
                    ↓
            crowley.py / tickets.py / github_read.py
```

Public OpenAPI documents **four** primary operations: `health`, `catalog`, `read`, `write`. Tool names (e.g. `memory.get`, `ticket.create`) come from `/catalog`.
