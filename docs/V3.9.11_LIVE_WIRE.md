## What changed

V3.9.10 answered **what to work on** (task frame). V3.9.11 answers **what's moving right now**:

1. **Pulses** — short-lived agent signals (`session_start`, `claimed`, `handoff`, `minted`, …)  
2. **Wire builder** — merges pulses, ticket events, handoffs; dedupes; ambient fallbacks when quiet  
3. **Compose footer** — orange beacon + news-ticker rotation for wire lines  
4. **Sync exposure** — `In the air` block in `cursor_sync --before` / `codex_sync --before`  
5. **Brain switcher** — switch provider/model in the header; chat uses selection immediately  

Authority order unchanged: filesystem → tickets → agent activity → project_state → canon → retrieval.
