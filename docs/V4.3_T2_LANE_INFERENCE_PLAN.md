## Goal

Apply rules-first **lane inference** from query text so retrieval filters the candidate pool **before scoring**. Explicit `?lane=` / `lanes=` overrides inference. Multi-lane inference is preserved for cross-domain queries. `secondary_lanes_json` may **boost** score when it intersects the filter set, but must **not** widen the primary-lane SQL filter.

**Non-goals for T2:** query-mode scoring profiles (T3), 8–15 caps (T4), chat/`build_prompt`, V4.2 ingest, `crowley_tools` contract changes.

---

## Problem (current state)

| Area | Today |
|------|-------|
| Explicit `lanes=` | Already filter-before-score via `_lane_clause` / `_load_spark_row` |
| `interpret_query().inferred_lanes` | Emitted as hint only; orchestration does **not** pass into `retrieve_sparks` |
| Lane keywords | Exact `SPARK_LANES` + `DOMAIN_ALIASES` only (e.g. `finance`→`money`) |
| `secondary_lanes_json` | Stored/validated; ignored by retrieval filter and score |
| Trace `lanes_used` | Explicit filter only; empty when inference would apply |

---

## Design principles

1. **Filter before score** — inferred/explicit lanes flow into existing candidate builders; do not post-filter after `_score_spark`.
2. **Explicit wins** — any non-empty caller `lanes` / `?lane=` overrides inference entirely (no merge/intersect).
3. **Multi-lane OK** — money+health phrasing keeps both inferred lanes.
4. **Secondary boost ≠ filter bypass** — primary `lane` column remains the only SQL/IN gate.
5. **Rules-only** — no LLM lane calls; extend keyword maps deterministically.
6. **Preserve contracts** — no `crowley_tools` rewrite; no V4.2 ingest changes; no weight-profile / cap work.

## Pipeline insertion

```
GET /api/cognitive/context?q=...&lane=...
  → build_cognitive_context(query, lanes=lane, ...)
      → interpretation = interpret_query(query)
      → resolved_lanes =
            explicit lanes if provided
            else frozenset(interpretation.inferred_lanes) if non-empty
            else None
      → retrieve_sparks(..., lanes=resolved_lanes)   ← APPLY inference here
      → trace.lanes_used = sorted(resolved_lanes or [])
      → trace.lane_source = explicit|inferred|none
      → debug.inferred_lanes = interpretation.inferred_lanes  (unchanged hint dump)
```

`retrieve_sparks` itself stays lane-agnostic about *how* lanes were chosen; orchestration owns resolve (matches T1 ownership). Optional: direct `retrieve_sparks` callers with `lanes=None` may auto-infer — **default plan: orchestration-only apply** unless Codex wants retrieval-side auto for non-context callers.

## 2. Resolve + apply in `context_orchestration.py`

```python
explicit = _normalize_lanes(lanes)
if explicit is not None:
    lane_filter = explicit
    lane_source = "explicit"
elif interpretation.inferred_lanes:
    lane_filter = frozenset(interpretation.inferred_lanes)
    lane_source = "inferred"
else:
    lane_filter = None
    lane_source = "none"
```

Trace always:

- `lanes_used`: sorted list (or `[]` when none)
- `lane_source`: `explicit|inferred|none`

Debug (when `debug=True`): keep `inferred_lanes` + `query_hints`; do not claim filter applied when `lane_source=none`.

Update T1 wire test that currently asserts `lanes_used == []` for decision queries with no domain words — still valid. Add/adjust tests where money/finance queries set `lanes_used == ["money"]`.

## 3. Secondary-lane score boost (`spark_retrieval.py`)

**Do not change** `_lane_clause` / `_load_spark_row` primary-only gate.

In `_score_spark` (or immediately after, inside `_rank_spark_candidates`):

1. If `lanes` is None → no boost.
2. Decode `secondary_lanes_json` via `sparks._decode_secondary_lanes`.
3. If any secondary lane intersects `lanes` **and** primary `row["lane"]` is already in `lanes` (row survived filter) → apply small multiplicative boost.

Proposed constant:

```python
SECONDARY_LANE_SCORE_BOOST = 1.05
```

Record in `score_breakdown`:

```python
breakdown["secondary_lane_boost"] = 1.05  # or 1.0 when not applied
```

Final score = existing hybrid × certainty × secondary boost (round as today).

**Not in T2:** changing `W_SPARK_*` base weights (T3).
