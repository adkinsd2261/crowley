V4.3 hardens the cognitive **read path**: rules-first query interpretation, auto
lane inference before scoring, query-mode scoring profiles, and a hard 8–15 spark
cap on default medium depth. Chat still uses legacy `memory_items` via
`build_prompt` — cognitive context wiring is V4.4.

## Architecture

```
GET /api/cognitive/context  /  cognitive.context
  -> cognitive_query.interpret_query (mode + inferred_lanes)
  -> lane resolve: explicit > inferred > none
  -> spark_retrieval.retrieve_sparks(
       lanes=..., query_mode=mode,
       limit=total_cap+1, expand_seed_limit=total_cap
     )
  -> split core/supporting; trace (query_mode, lane_source, score_profile,
     retrieved_count, truncated_count, ...)
```
