**Status:** Shipped (V3.5), extended through V3.7.2 live UI sync

**Approved:** 2026-06-30  
**Shipped:** 2026-06-30 (core); live dashboard 2026-07-01

---

## Decisions (locked)

| Decision | Choice |
|----------|--------|
| Default port | `8765` |
| Bind address | `127.0.0.1` only |
| Chat history API | `GET /api/messages` — **MVP requirement** |
| Web slash commands | Rejected with friendly hint; CLI remains command surface |
| Diagnostics output | In-chat diagnostics block |
| Sparks panel | Summary sparks only (`importance >= 2`) |
| Stack | FastAPI + static HTML/CSS/JS |
| Architecture | UI is cockpit only; `crowley.py` is source of truth |

---

## Architecture

```
Browser (static/)  →  HTTP/SSE  →  app.py (transport)  →  crowley.py (engine)  →  crowley.db
CLI (crowley.py main)  ────────────────────────────────────────┘
```

**Hard constraint:** No Crowley business logic in `app.py` or frontend.

## API routes

| Method | Path | Purpose |
|--------|------|---------|
| GET | `/` | Serve `static/index.html` |
| GET | `/api/health` | Version, provider, DB ok |
| POST | `/api/chat` | SSE chat via `chat_turn()` |
| GET | `/api/messages?limit=50` | Recent chat history |
| GET | `/api/world` | Live dashboard — state, panels, phase progress, `synced_at` |
| GET | `/api/diagnostics` | SSE read-only briefing |
| GET | `/api/tasks` | Open tasks |
| POST | `/api/tasks/{id}/done` | Mark task done (V3.7.2) |
| GET | `/api/loops` | Open loops |
| GET | `/api/decisions` | Recent decisions |
| GET | `/api/memory-items` | Recent `memory_items` (V3.7.2) |
| GET | `/api/sparks` | Legacy summary sparks (`memories` table) |

### POST /api/chat (SSE)

Events: `status` (thinking) → `token` → `done` | `error`

Slash commands (`/...`) rejected before engine call with hint to use terminal.

### GET /api/diagnostics (SSE)

Same event shape. Read-only — no `ask_crowley`, no writes.

## Frontend layout

- Dark command-center theme
- Center: chat + input + thinking state + **current objective** + **phase chip** (V3.7.2)
- Right sidebar: project state, **phase progress bar**, sync timestamp, Diagnostics button
- Collapsible **Intelligence** drawer: tasks (with ✓ done), loops, decisions, memory
- **Live sync pill** — polls `/api/world` every 5s (V3.7.2)
- Diagnostics render as in-chat block labeled "Diagnostics briefing"
- Refresh on chat `done`, poll interval, and tab focus

## Phase 6 — Visual polish direction

**Reference:** UI mockup (atmosphere only — not a pixel-perfect target).

### Identity

Crowley web UI should feel like:

- ChatGPT workspace usability
- local AI operating system cockpit
- premium dark productivity dashboard

**Not:** iMessage-style chat, cheap cyberpunk, sci-fi clutter, fake radar, neon pumpkin orange.

### Palette

| Role | Direction |
|------|-----------|
| Foundation | Charcoal, graphite, near-black, soft grey |
| Accent | Rust / burnt orange (`#c45c26` family) — not neon |
| Glow | Sparingly: focused input, diagnostics hover, health dot, active borders |
| Avoid | Cheap gradients, noisy backgrounds, glow everywhere |

### Layout (workspace, not messaging app)

- Central **workspace** for chat output (full-width blocks, not social bubbles)
- **Command console** input at bottom (strongest orange glow on `:focus`)
- **Project State** glass sidebar (right)
- **Tasks / Loops / Decisions / Sparks** as bottom workspace panels
- **Run Diagnostics** as a system action (sidebar, uppercase, orange outline)

### Glass language

- Panels use subtle transparency + `backdrop-filter`
- Thin borders (`rgba(255,255,255,0.07–0.11)`)
- Rust-orange borders for headings and primary actions only

### Icons

- Omitted by default in V3.5 polish
- If added later: simple line icons only, never decorative clutter

### Mockup used for

- Layout density and hierarchy
- Dark glass tile feel
- Orange outline language
- Premium polish

### Mockup NOT used for

- Exact icons, fake nav menus, decorative labels, cyberpunk effects

### Implementation (Phase 6)

- `static/styles.css` — primary changes (design tokens, glass, accent system)
- `static/index.html` — minor structure (workspace toolbar, tagline)
- No backend changes; no `crowley.py` changes; plain CSS only

## UX redesign — workspace, not chatbot

**Insight:** Crowley is a persistent OS for long-running thinking. The UI should feel like stepping into a workspace, not texting an AI.

### Hierarchy

1. **Workspace** (primary) — document stream + composer
2. **Project inspector** (secondary) — right sidebar
3. **Context drawer** (tertiary) — collapsible, tabbed tasks/loops/decisions/sparks

### Workspace entries

- No bubbles, no messenger layout
- Document-style blocks with generous whitespace
- Composer: “What are we building today?” + **Continue** (not Send)
- Thinking: rust-orange **breathing orb** (hidden when tokens stream)

### Context panels

- Collapsed by default — single “Context” bar with summary counts
- Expand to tabs — reduces permanent dashboard weight

### Visual restraint

- Graphite/charcoal foundation, rust-orange for focus/thinking/actions only
- Premium, minimal, no sci-fi clutter
