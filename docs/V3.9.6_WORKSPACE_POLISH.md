# Crowley V3.9.6 -- Workspace Polish

**Status:** Planned
**Baseline:** V3.9.5 Conversation + Model Behavior
**Plan:** [PRE_V4_QUALITY_PLAN.md](./PRE_V4_QUALITY_PLAN.md)

---

## 1. Goal

Make the browser workspace livable for daily use by removing dead states, smoothing streaming, tightening navigation, and making recent work obvious.

Done when Crowley can be used for a week without the frontend feeling half broken.

---

## 2. Scope

| Ticket | Slice | Outcome |
|--------|-------|---------|
| #31 | Loading/error/empty states | No blank panels during loading, offline, or empty data |
| #32 | Smoother streaming | Chat has clear start, token flow, completion, and error behavior |
| #33 | Navigation + panel flow | Intelligence tabs and ticket detail feel predictable |
| #34 | "What changed" feed | Recent Cursor/Codex work is visible without raw handoff reading |
| #35 | Frontend livability pass | Spacing, overflow, mobile-ish widths, and dead affordances improved |
| #36 | Final docs + version lock | Release docs and current-state docs are ready for V4 |

---

## 3. Non-goals

- No visual redesign.
- No V4 collectors.
- No multi-project implementation.
- No model provider changes.
- No replacing the ticket board with another workflow surface.

---

## 4. Acceptance gate

- Chat, Tickets, Agent Feed, Memory, diagnostics, and ticket detail have clear loading/error/empty states.
- Streaming start, completion, and error states are visible and stable.
- Intelligence drawer navigation is predictable.
- Selected ticket detail does not flicker unnecessarily.
- "What changed" is assembled from existing activity/ticket/handoff data.
- The UI is usable at desktop and mobile-ish widths.
- Docs are synchronized before V4 starts.

---

## 5. QA

- Focused UI/static tests for state rendering and panel behavior.
- Full regression: `python -m unittest discover -s tests -q`.
- Manual browser QA:
  - Chat empty and model-error behavior where feasible.
  - Streaming start/completion/error.
  - Tickets list and ticket detail.
  - Agent Feed.
  - Memory panel.
  - "What changed" feed.
