# Crowley V3.9.6 — Workspace Polish

**Status:** Shipped (2026-07-02)
**Baseline:** V3.9.5 Conversation + Model Behavior
**Plan:** [PRE_V4_QUALITY_PLAN.md](./PRE_V4_QUALITY_PLAN.md)

---

## 1. Goal

Make the browser workspace livable for daily use by removing dead states, smoothing streaming, tightening navigation, and making recent work obvious.

Done when Crowley can be used for a week without the frontend feeling half broken.

---

## 2. Scope (shipped)

| Ticket | Slice | Outcome |
|--------|-------|---------|
| #31 | Loading/error/empty states | Panel states via `renderPanelState`; no blank panels on load/offline/empty |
| #32 | Smoother streaming | RAF-batched tokens, writing indicator, `aria-busy`, reliable finalize/abort |
| #33 | Navigation + panel flow | Session tab/ticket persistence; fingerprint-gated panels; stable ticket detail |
| #34 | "What changed" feed | `build_recent_changes_feed()` + Intelligence Changes tab |
| #35 | Frontend livability pass | Overflow/wrap fixes, drawer heights, Refresh safety during streaming |
| #36 | Final docs + version lock | This doc, onboarding lock, `3.9.6` constants, bus restart QA |

**Follow-up patch:** Changes tab falls back to `agent_activity.recent` when `recent_changes` is missing from a stale bus.

---

## 3. Non-goals

- No visual redesign.
- No V4 collectors.
- No multi-project implementation.
- No model provider changes.
- No replacing the ticket board with another workflow surface.
