Crowley is the **persistent context layer** that follows D across reasoning surfaces. The browser UI is one cockpit; ChatGPT, Claude, Codex, Cursor, and local models are terminals. V3.9.12 Portable Context Terminal and V4.0 Spark Lanes follow on the existing board order.

## Operator notes

Agent sync after V3.9.9 is intentionally slimmer — assigned tickets and blockers appear before memory dumps:

```bash
./venv/bin/python3 scripts/cursor_sync.py --before
./venv/bin/python3 scripts/codex_sync.py --before
```

Hygiene report (read-only, no writes):

```bash
curl -s http://127.0.0.1:8765/api/hygiene | python3 -m json.tool
```

Post-work feedback on handoff close:

```bash
./venv/bin/python3 scripts/cursor_sync.py --after --ticket 42 \
  --summary "what shipped" \
  --lesson "one durable lesson" \
  --state-changed "phase or focus changed"
```

Preflight: `./venv/bin/python3 scripts/preflight.py --quick`
