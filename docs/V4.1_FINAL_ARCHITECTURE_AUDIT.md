# V4.1 Final Architecture Audit And Lock

**Status:** Shipped / locked  
**Date:** 2026-07-09  
**Version:** `CROWLEY_VERSION = "4.1.0"`  
**Release label:** `Crowley V4.1 Architecture and MCP Readiness`  
**Tickets:** #316-#325  
**Owner:** Codex

V4.1 is a foundation release. It decomposes `crowley.py` while keeping it as the
import-compatible facade, locks a practical local security baseline, and prepares
Crowley's tool layer for a future MCP transport without shipping MCP yet.

## Final Decision

V4.1 is locked.

The user-facing behavior contract remains stable:

- HTTP routes remain stable.
- CLI commands remain stable.
- ChatGPT Actions catalog/read/write routes remain stable.
- Agent sync and portable packet payloads remain stable.
- Database schema remains stable.
- `import crowley` remains the compatibility contract.

## Architecture Outcome

Baseline from the V4.1 boundary doc:

- `crowley.py` before V4.1 extraction: 10,218 lines.
- `crowley.py` after V4.1 extraction: 6,144 lines.
- Reduction: 4,074 lines, about 39.9 percent.

## Security Lock

V4.1 locks the local-first security posture:

- Full internal `/api/*` stays localhost/trusted-local.
- `/api/actions/*` remains bearer-gated by `CROWLEY_ACTION_KEY`.
- Public tunnel config remains API-only for Actions routes.
- Actions write tools keep permission and workflow gates.
- Cognitive context remains bounded, redacted, and `MEMORY_DATA` wrapped.
- Secret-like spark content remains rejected at validation time.
- Secret hygiene remains read-only and redacted.

Deferred security work remains explicit:

- field-level encryption
- OAuth/accounts/public hosting
- localhost UI auth
- automatic secret cleanup/quarantine

## End-To-End Wiring Audit

Checked and locked:

- `app.py` continues to call `crowley.py` facade functions.
- `python crowley.py` delegates into `cli_shell.py`.
- Prompt/chat behavior delegates into `conversation_runtime.py`.
- Core DB/runtime helpers delegate into `crowley_core.py` and `model_runtime.py`.
- Memory storage/retrieval delegates into `memory_store.py`,
  `memory_embeddings.py`, and `memory_retrieval.py`.
- World dashboard/context/agent sync/portable packet flows delegate into
  `world_state.py`, `agent_sync_bundle.py`, and `portable_context.py`.
- `actions_tool_registry.py` consumes `crowley_tools.ToolDefinition` metadata.
- ChatGPT Actions legacy aliases and read/write gateways still route through the
  same registry.

## Remaining Debt

Deferred intentionally:

- MCP server and transport adapter.
- MCP permission prompts, auth parity, and rate-limit parity.
- `app.py` router split.
- Actions registry domain split.
- Field-level encryption.
- Cognitive review UX.
- Truth arbitration for large/conflicting spark sets.
- Workflow determinism beyond current Actions gates.
- Voice/TTS/device work.
- Event-driven automation.
- Full schema migration framework.

## Release Rule Going Forward

V4.1 changed architecture, not user-facing behavior. Future work should keep
domain logic out of `crowley.py`, use focused modules, and treat
`crowley_tools.py` as the source of truth for external tool contracts.
