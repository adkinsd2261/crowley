## Goal

Split long cognitive ingest into bounded sections, apply **per-chunk** temporary/noise intent decisions, and attach all useful sparks to **one** receipt with shared lineage. A single temporary or noise section must **not** discard useful chunks from the same paste.

---

## Codex revision (#2269)

**Rejected in v1:** whole-document `classify_memory_intent()` running before chunking — a mixed long document with one temporary marker could be classified `temporary`/`ignore` at the top level and never chunked.

**v2 fix:** narrow whole-document gate to hard blocks only; chunk long input first; run full T1 intent per chunk.

---

## Pipeline insertion

### Short input (`len <= CHUNK_THRESHOLD`)

Unchanged T1 behavior — full `classify_memory_intent()` on the whole paste:

```
POST /api/cognitive/ingest
  → _save_cognitive_receipt
  → classify_memory_intent(whole document)    ← T1 unchanged
      → ignore / temporary → skip extraction
      → store → _run_extraction_pipeline()
```

### Long input (`len > CHUNK_THRESHOLD`)

```
POST /api/cognitive/ingest
  → _save_cognitive_receipt
  → classify_ingest_precheck(whole document)   ← NEW narrow gate
      → ignore (security | all-noise) → skip entire ingest
      → proceed:
          → chunk_cognitive_text(content)      ← chunk BEFORE temporary/noise
          → for each chunk:
                classify_memory_intent(chunk)  ← T1 per chunk
                ignore / temporary → skip chunk only
                store → extract_sparks_from_text(chunk)
          → merge spark_ids + chunk_manifest on receipt
```

**Receipt `non_retrieval`:** set only when **zero** chunks produced sparks **and** every chunk was skipped (all-noise/temporary) — not when at least one chunk stored.

## `cognitive_intent.py` addition

```python
def classify_ingest_precheck(text: str) -> MemoryIntentResult | None:
    """
  Hard blocks for long ingest only. Returns None → proceed to chunking.
  Must NOT classify temporary markers or partial noise on mixed documents.
    """
```

| Check | Result |
|-------|--------|
| `sparks._spark_content_security_errors()` non-empty | `ignore` (`content_security`) |
| Empty or &lt;4 meaningful chars | `ignore` (`all_noise`) |
| Entire paste is greeting/noise tokens only (same as T1 noise rule on **whole** text) | `ignore` (`all_noise`) |
| Otherwise | `None` (proceed — temporary/mixed decisions deferred to per-chunk) |

**Explicitly excluded from precheck:** `temporary_marker`, `slash_command` (unless entire paste is a single slash line), `substantive_content`, `ambiguous_content`. A long paste starting with `remind me later today only` **must not** precheck-block if body contains substantive sections.

Optional helper: `is_all_noise_document(text) -> bool` — true only when every would-be chunk would fail the noise greeting rule (used in tests).

## New module: `cognitive_chunking.py`

```python
@dataclass(frozen=True)
class CognitiveChunk:
    index: int
    text: str
    break_reason: str  # single | heading | paragraph | size_limit

@dataclass(frozen=True)
class ChunkingResult:
    chunks: list[CognitiveChunk]
    truncated: bool
    omitted_chunk_count: int
```

### `chunk_cognitive_text(text: str) -> ChunkingResult`

Rules-first splitter (no LLM):

| Order | Rule | Action |
|-------|------|--------|
| 1 | `len(text) <= CHUNK_THRESHOLD` (4096) | Return single chunk (`break_reason=single`) — caller uses short path |
| 2 | Split on markdown ATX headings (`^#{1,6}\s`) | Section boundaries |
| 3 | Split on horizontal rules (`^---+$`) | Section boundaries |
| 4 | Split on blank-line paragraph gaps (`\n\n+`) | Paragraph boundaries |
| 5 | Merge fragments &lt; `MIN_CHUNK_CHARS` (80) into previous segment | Avoid micro-chunks |
| 6 | Pack segments into chunks ≤ `MAX_CHUNK_CHARS` (3500) | Hard size cap per extraction call |
| 7 | If chunk count &gt; `MAX_CHUNKS` (8) | Keep first 8; set `truncated=True`, `omitted_chunk_count` |

### Constants

```python
CHUNK_THRESHOLD_CHARS = 4096
MAX_CHUNK_CHARS = 3500
MAX_CHUNKS = 8
MIN_CHUNK_CHARS = 80
```

## `cognitive_ingest.py` changes

### Routing

```python
if len(content) > CHUNK_THRESHOLD_CHARS:
    precheck = classify_ingest_precheck(content)
    if precheck is not None and precheck.intent == "ignore":
        return skip_entire_ingest(precheck)
    return run_chunked_extraction(...)
# else: existing T1 short-path (unchanged)
```

### `_run_chunked_extraction_pipeline(...)`

1. `chunking = chunk_cognitive_text(text)`
2. `extraction_id = uuid4()` — one batch id per receipt
3. For each chunk:
   - `chunk_intent = classify_memory_intent(chunk.text)`
   - If `ignore` / `temporary`: record in `chunk_manifest` as skipped; **continue**
   - Else: extract + upsert with lineage:

```python
lineage_json={
    "memory_item_id": memory_item_id,
    "extraction_id": extraction_id,
    "chunk_index": chunk.index,
    "chunk_count": len(chunking.chunks),
    "chunk_break_reason": chunk.break_reason,
}
```

4. Partial chunk extraction failures do not roll back prior chunk sparks.
5. Receipt metadata:

```python
{
    "extraction_status": "complete" | "partial" | "failed" | "skipped_intent",
    "chunking": {"chunk_count", "truncated", "omitted_chunk_count",
                 "chunks_processed", "chunks_skipped_intent"},
    "chunk_manifest": [{"index", "intent", "reason", "spark_count"}, ...],
    "spark_ids": [...],
    "non_retrieval": True,  # only when spark_count == 0 and all chunks skipped
}
```

### API response (long + mixed)

Top-level `intent` reflects precheck outcome or aggregate:

```json
{
  "status": "ok",
  "memory_item_id": 123,
  "intent": {"intent": "store", "confidence": 0.92, "reason": "chunked_ingest"},
  "extraction": {
    "ok": true,
    "spark_ids": [1, 2],
    "chunking": {"chunk_count": 3, "chunks_skipped_intent": 1, "truncated": false},
    "extraction_id": "..."
  }
}
```

## Messy-input example (acceptance matrix alignment)

**Input:** 5KB paste = line 1 `remind me to check this later today only` + `## Work` section (1.5KB) + `## Money` section (1.5KB)

| Step | Result |
|------|--------|
| Precheck | `None` — not all-noise; not security |
| Chunk 0 | `temporary` → skipped |
| Chunk 1 | `store` → work-lane sparks |
| Chunk 2 | `store` → money-lane sparks |
| Receipt | `spark_count >= 2`, `chunks_skipped_intent == 1`, **not** `non_retrieval` |

v1 would have classified the whole paste `temporary` and extracted nothing.
