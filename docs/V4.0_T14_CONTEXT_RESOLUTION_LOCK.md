## What shipped

Cross-system context arbitration folded into the production Actions path:

```
retrieve_memories → cross_source_resolve → depth-limited bundle
```

| Area | Module | What |
|------|--------|------|
| Resolver | `context_resolution.py` | Cluster same-topic signals; dominance handoff > memory > ticket; suppress duplicates; attach `related_signals` |
| Context bundle | `crowley.py` | `build_context_bundle(depth=, debug=)`; `source_text` on retrieve for accurate clustering |
| Actions | `actions_tool_registry.py` | `context.get` + `retrieve.search` accept `depth` (default `medium`) and `debug` |
| Cognitive | `context_orchestration.py` | `depth=light\|medium\|deep`; cold-start `memory_fallback` when active sparks < 10 |
| HTTP | `app.py` | `/api/context`, `/api/retrieve`, `/api/cognitive/context` depth params |
| Tool fixes | `actions_tool_registry.py`, `tickets.py` | `ticket_id` alias, `ticket.list sort=newest`, handoff `details`/`type` aliases |

---

## Depth modes

| Depth | `relevant_memories` | `matched_tickets` | Cognitive supporting |
|-------|---------------------|-------------------|----------------------|
| `light` | ≤12 resolved clusters | none | 0 |
| `medium` (default on Actions) | ≤12 resolved | ≤5 query-matched | ≤20 |
| `deep` | ≤20 resolved | ≤10 | ≤20 + expand related |

Legacy callers without `depth` get **unresolved** raw retrieval (backward compatible).
