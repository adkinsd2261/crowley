# Crowley V3.8.1 — Agent Parity

**Status:** Shipped (2026-07-01)  
**Release:** `CROWLEY_VERSION = "3.8.1"`, `CROWLEY_RELEASE_LABEL = "Crowley V3.8.1 Agent Parity"`  
**Baseline:** V3.8 Memory Trail + multi-agent sync

---

## 1. Purpose

V3.8 shipped the multi-agent hub (`/api/agent/sync`, sync scripts, Cursor hooks). V3.8.1 **tightens the wiring** so agents, APIs, and Crowley's chat all read the same truth about who posted what and when.

Problems addressed:

1. Crowley could not reliably answer "when did you last hear from Cursor?" — hybrid retrieval ranked wrong rows.
2. `/api/context` lacked `agent_activity` while chat prompts had it — API parity gap.
3. Post-ingest verify used fuzzy `/api/retrieve` — false negatives after good ingests.
4. Cursor hooks only ran `--before` — sessions could close without handoffs.
5. `cursor_sync --before` was thinner than `codex_sync --before`; event display showed `None |` prefixes.

## 2. Shipped surface

### Engine (`crowley.py`)

| Function | Change |
|----------|--------|
| `_agent_activity_summary()` | `last_by_source` for cursor, codex, chatgpt |
| `build_prompt()` | Injects **Agent activity** block every chat turn |
| `build_context_bundle()` | Top-level `agent_activity` key |
| `build_agent_sync_bundle()` | Top-level `agent_activity` key |
| `build_world_dashboard()` | Includes `agent_activity` for UI |

### Shared library (`scripts/agent_sync_lib.py`)

| Helper | Role |
|--------|------|
| `event_display_line()` | One-line CLI event text (no bare `None`) |
| `verify_agent_handoff(agent)` | Confirm ingest via `last_by_source` on `/api/agent/sync` |
| `print_agent_sync_bundle()` | Shared `--before` header (role, phase, events, last contact) |
| `print_sync_extras()` | Decisions, loops, retrieved memories |
| Session markers | `touch_session_marker()`, `handoff_since_session()`, `clear_session_marker()` |

### Cursor hooks (`.cursor/hooks.json`)

| Hook | Script | Action |
|------|--------|--------|
| `sessionStart` | `session-start.sh` | Bus up → `--session-start` → `--before` |
| `beforeSubmitPrompt` | `prompt-submit.sh` | `--before` (silent) |
| `stop` | `session-stop.sh` | `--session-end` — warn if no handoff since session start |

### Sync scripts

Both `codex_sync.py` and `cursor_sync.py`:

- Import `agent_sync_lib` for verify and display
- `_ingest_and_verify()` returns bool; prints `agent_activity` confirmation

`cursor_sync.py` additionally:

- `--session-start` / `--session-end` for hook use
- Enriched `--before` output (parity with Codex)

## 4. Agent ritual (updated)

### Cursor (builder)

```bash
# Before work (hooks auto-run)
./venv/bin/python3 scripts/cursor_sync.py --before

# After shipping
./venv/bin/python3 scripts/cursor_sync.py --after \
  --summary "what shipped" \
  --next-action "what happens next" \
  --qa-result "tests run"

# Quick update
./venv/bin/python3 scripts/cursor_sync.py --note "short status"
```

Close session without `--after`/`--note` → `stop` hook stderr warning.

### Codex (architect)

Primary path remains `codex_sync.py --after` / `--note`. Verify now uses `agent_activity`.
