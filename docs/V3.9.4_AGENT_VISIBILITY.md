## 1. Purpose

V3.9.2 made memory auditable; V3.9.3 made planning repeatable. V3.9.4 **makes multi-agent work visible in the browser** and **locks onboarding docs** so V4 connectivity starts from a clean baseline.

Problems addressed:

1. Agent handoffs and ticket progress were only visible via CLI sync or SQLite.
2. Tickets, legacy tasks, and open loops were easy to confuse in the Intelligence drawer.
3. Pre-V4 features shipped under version constant `3.9.1` — onboarding docs needed a single shipped label.
