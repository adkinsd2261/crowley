V4.2 hardens the cognitive ingest path before retrieval/chat work: rules-first intent
gating, additive spark schema fields, long-document chunking, candidate→active
promotion policy, and extraction determinism. Chat still uses legacy `memory_items`
via `build_prompt` — cognitive context wiring is V4.4.

## Architecture

```
POST /api/cognitive/ingest
  -> cognitive_intent (store | ignore | temporary)
  -> cognitive_chunking (long pastes only, >4KB)
  -> spark_extraction (temp=0, canonicalize, receipt-hash cache)
  -> sparks.validate_spark + upsert
  -> spark_lifecycle auto-promotion (confirmed + eligible only)
```
