## Scope

V3.9.13 proved bearer-authenticated `/api/actions/*` over a named Cloudflare tunnel (`api.javlin.ai`). V3.9.14 hardens **operator/runtime durability** — no new ChatGPT capabilities.

| In scope (#82–#86) | Out of scope |
|--------------------|--------------|
| macOS LaunchAgent durable connector | New Actions routes |
| Hardened `start_chatgpt_bridge.sh` | OAuth / multi-user auth |
| API-only tunnel ingress templates | Exposing full `/api/*` or UI |
| `verify_chatgpt_bridge.py` operator verify | V4 Spark Lanes architecture |
| `crowley_bridge_service.py` install/status | Binding Crowley to `0.0.0.0` |

---

## Architecture

- **Crowley** stays on `127.0.0.1:8765`
- **Public hostname** `api.javlin.ai` (operator example) forwards only `^/api/actions/.*`
- **LaunchAgent** (`com.crowley.chatgpt-bridge`) keeps `cloudflared` alive after login/restart
- **Bearer auth** `CROWLEY_ACTION_KEY` on every Actions route
