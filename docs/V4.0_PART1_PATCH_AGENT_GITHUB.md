## Shipped (#229–#231 + GitHub hardening)

### Agent sync — Adaptive Sync Envelope (ASE)

| Ticket | Module | What landed |
|--------|--------|-------------|
| #231 | `crowley.py`, `tickets.py` | `limit` drives per-section caps (handoffs, tickets, memory, events); removed memory floor bug |
| #229 | `agent_sync_envelope.py` | 180KB payload cap; handoffs → tickets → memory priority; compressed list items; `sync_meta` |
| #230 | `agent_sync_envelope.py`, `app.py`, `actions_tool_registry.py` | `GET /api/agent/deep_sync`, `agent.deep_sync` cursor pagination |

- `finalize_agent_sync_bundle()` runs after runtime attach on API/Actions paths
- `bundle_shape: ase_v1` when envelope applied

### GitHub Actions — bounded read envelope

| Area | Guard |
|------|--------|
| `github.file` | 100KB decoded content cap; large `download_url`-only files rejected with message |
| Payload envelope | 180KB total per tool response |
| `github.search_code` | Max 10 slim items; query capped at 256 chars |
| `github.compare` | Patches stripped; max 40 files |
| Errors | Structured `github_read_failed` at HTTP 200 (not origin 502) |
| Timeout | 10s + one retry on 5xx/timeout |
