## What shipped

Bidirectional ticket ↔ memory index layered on the restored `#1–#264` ticket arc.

```
memory_items.linked_ticket_ids_json  ←→  tickets.linked_memory_id
         ↑ infer/backfill                    ↑ handoff bridge
    ticket.get?include_memories=true
    planning.ticket (always includes memories)
    retrieve.search (query-ticket boost)
```

| Area | Module / script | What |
|------|-----------------|------|
| Schema | `memory_ticket_linkage.py` | `linked_ticket_ids_json` on `memory_items` |
| Infer + persist | `memory_ticket_linkage.py` | Regex/metadata/reverse handoff link; backfill |
| Ticket detail | `tickets.py`, `app.py` | `include_memories`, grouped `linked_memories` |
| Actions | `actions_tool_registry.py` | `ticket.get` `include_memories`, `memory_limit` |
| Handoff ingest | `crowley.py`, `tickets.py` | Sync memory links on ingest + `linked_memory_id` set |
| Retrieval | `crowley.py` | Persisted links + query `#N` ticket boost |
| Lineage | `tickets.py`, `agent_sync_envelope.py` | `sort=oldest`, `tickets.lineage`, `deep_sync scope=history` |
| Bridge fix | `handoff_ticket_bridge.py` | Next Action `#N` excluded from false-close |
| Audit | `scripts/audit_ticket_lineage.py` | Ticket continuity report |
| Audit | `scripts/audit_memory_ticket_linkage.py` | Memory↔ticket coverage % |
| Backfill | `scripts/backfill_memory_ticket_linkage.py` | `--apply` persisted links |

## Operator verify

**Local REST (no auth):**

```bash
curl -s "http://127.0.0.1:8765/api/tickets/216?include_memories=true" \
  | jq '.linked_memories_total, (.linked_memories | keys)'
```

**Actions API (`127.0.0.1:8765` or public tunnel — not port 8080):**

```bash
source .env
curl -s -H "Authorization: Bearer $CROWLEY_ACTION_KEY" \
  -H "X-Crowley-Session: verify" -H "Content-Type: application/json" \
  -X POST http://127.0.0.1:8765/api/actions/read \
  -d '{"tool":"agent.sync","args":{"agent":"chatgpt","limit":5}}'

curl -s -H "Authorization: Bearer $CROWLEY_ACTION_KEY" \
  -H "X-Crowley-Session: verify" -H "Content-Type: application/json" \
  -X POST http://127.0.0.1:8765/api/actions/read \
  -d '{"tool":"ticket.get","args":{"id":216,"include_memories":true}}' \
  | jq '.linked_memories_total, (.linked_memories | keys)'
```
