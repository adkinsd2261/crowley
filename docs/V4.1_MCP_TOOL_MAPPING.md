# V4.1 MCP Tool Mapping

V4.1 does not ship an MCP server. It prepares one by moving Crowley tools behind a
transport-neutral contract in `crowley_tools.py` and making the Actions registry
consume that contract.

ChatGPT Actions remains the external compatibility contract in V4.1:

- `/api/actions/catalog` keeps the existing `actions_tool_catalog_v1` shape.
- `/api/actions/read` and `/api/actions/write` keep current dispatch behavior.
- Legacy Actions aliases continue to delegate to the same handlers.
- MCP metadata is internal-only until a future transport is implemented.

## Classification Rules

- `mcp_safe`: read-oriented or validation-only tools that can be exposed later
  with normal MCP session/auth policy.
- `mcp_conditional`: write tools that need an MCP permission prompt, agent
  identity policy, audit logging, and rate-limit parity before exposure.
- `actions_only`: tools whose shape is specific to the current Actions sync loop.
- `local_only`: operator, inspection, or environment-dependent tools that should
  stay local unless separately approved.
- `blocked`: tools that should not be exposed through MCP.

## MCP-Conditional Writes

- `handoff.ingest`
- `note.ingest`
- `ticket.cancel`
- `ticket.create`
- `ticket.update`
- `writeback.ingest`

These require the same or stronger controls than Actions before MCP exposure:
agent identity, write permission checks, mutation invariants, audit visibility,
timeouts, and rate limits.

## Actions-Only

- `agent.deep_sync`
- `agent.sync`

These are bound to the Actions boot/sync contract and should be redesigned for
MCP rather than lifted directly.

## Blocked

- `audit.rollback`

Rollback can alter prior writes and should stay out of MCP unless a future
operator-only flow is explicitly designed.

## Adapter Status

`actions_tool_registry.py` now registers `crowley_tools.ToolDefinition` objects.
At registration, it fills transport-neutral metadata:

- timeout seconds from `actions_tool_runtime`
- workflow tier from `workflow`
- permission tier from `crowley_tools`
- MCP exposure classification from `crowley_tools`

The Actions catalog projects only legacy fields: `name`, `kind`, `tier`,
`description`, and `args_schema`.
