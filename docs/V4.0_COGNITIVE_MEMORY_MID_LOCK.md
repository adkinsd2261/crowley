## Architecture invariants (locked so far)

1. **Separate tables:** `memory_items` (raw receipt) → `sparks` → `patterns` — do not remove `memory_items`.
2. **Deterministic retrieval:** no LLM in ranking, lane selection, graph traversal, or pattern attachment.
3. **LLM boundary:** OpenAI only in `spark_extraction.py` at ingest time.
4. **No hard delete:** archive to `rejected` only (enforcement continues in T16).
5. **Canonical score:** `0.40 semantic + 0.25 confidence + 0.15 recency + 0.20 graph_reinforcement`.
6. **Pattern promotion:** T12 owns `candidate` → `active`; no auto-canon.
7. **Context orchestration:** T13 calls `retrieve_sparks(expand_hops=…)` once — no double expansion.
