## What changed

Hybrid retrieval alone does not answer “where are we on this ticket?” V3.9.10 puts a structured **task frame** ahead of supporting memories everywhere agents and operator chat read context:

1. **Working on** — assigned/in_progress tickets with parsed acceptance and blockers  
2. **Last handoff** — summary + next_action for the requesting agent (not full prose)  
3. **Guardrails** — capped decisions and constraints  
4. **Supporting memories** — ticket-narrative retrieval (3–4 rows with `inclusion_reason`)

Authority order is unchanged: filesystem truth and tickets outrank retrieval ([MEMORY_HIERARCHY.md](./MEMORY_HIERARCHY.md)).
