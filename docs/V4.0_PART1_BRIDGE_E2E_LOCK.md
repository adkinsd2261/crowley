## Verified E2E (runtime truth)

| Step | Path | Result |
|------|------|--------|
| Boot | `POST /api/actions/read` `agent.sync` | 200 JSON |
| Write | `POST /api/actions/write` `writeback.ingest` (catalog `writeback` shape) | 201, `auto_promotion.applied: true` |
| DB | spark status after promote | `active` |
| Read | `POST /api/actions/read` `retrieve.search` with `q` | 200 `application/json`, `results` + `hits` |

**Operator rules:**

1. **Restart bus** after code changes (`./scripts/ensure_crowley_bus.sh` or LaunchAgent) — Python keeps old modules in memory.
2. **Do not** call `https://api.javlin.ai/api/retrieve` — tunnel exposes only `^/api/actions/.*` (404 empty body → client `ContentTypeError`).
3. Use **`q`** (or `query` alias) in `retrieve.search` args — not top-level `query` without `args`.
4. Run `./scripts/cleanup_chatgpt_bridge.sh` if duplicate `cloudflared` or wedged bus.
